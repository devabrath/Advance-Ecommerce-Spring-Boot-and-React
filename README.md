# 🛒 Advance E-Commerce Platform

A full-stack multi-vendor e-commerce platform built with **Spring Boot, React, TypeScript, and MySQL**.

## ✨ Features

* 👤 Customer authentication & profile
* 🛍️ Product search, filter & sorting
* 🛒 Cart & checkout
* 💳 Razorpay test payments
* 🏷️ Discount & coupon codes
* 📦 Order management & tracking
* 📧 Email order confirmation
* 🏪 Vendor dashboard & product management
* 👑 Admin dashboard & platform management
* 📊 Sales & revenue analytics
* 📱 Fully responsive UI

## 🛠️ Tech Stack

**Frontend:** React, TypeScript, Vite, Axios, Tailwind CSS

**Backend:** Java 17, Spring Boot, Spring Security, JWT, JPA/Hibernate

**Database:** MySQL

**Integrations:** Razorpay, Google OAuth, Email/SMTP

## 📁 Structure

```text
├── Backend
├── Frontend

```

## 🚀 Run

```bash
# Backend
cd Backend
mvn spring-boot:run

# Frontend
cd Frontend
npm install
npm run dev
```
