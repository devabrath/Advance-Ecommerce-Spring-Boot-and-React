# ⚙️ E-Commerce Backend

Spring Boot REST API for the Advance E-Commerce Platform.

## 🛠️ Tech Stack

* Java 17
* Spring Boot
* Spring Security & JWT
* Spring Data JPA / Hibernate
* MySQL
* Maven

## 📌 Features

* Authentication & authorization
* Product & category management
* Cart & orders
* Vendor & admin APIs
* Coupon management
* Razorpay payments
* Email notifications
* Sales analytics

## 🚀 Run

```bash
mvn spring-boot:run
```

Backend runs on:

```text
http://localhost:8080
```
